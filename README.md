# iOS ML Student Performance Predictor

An end-to-end Machine Learning project that integrates an **iOS frontend** with a **Python backend** to predict whether a student will pass an exam using a **Random Forest Classifier**.

This project demonstrates how a real ML system works from **model training → API → mobile app integration**.

---

## Project Overview

The goal of this project is to build a machine learning system that predicts student exam results based on:

* Hours studied
* Sleep hours
* Practice tests taken

The prediction is generated by a **RandomForestClassifier** trained using Scikit-learn and served through a **FastAPI backend**, which is then consumed by an **iOS application**.

---

## System Architecture

iOS App (Swift / URLSession)
↓
FastAPI Backend
↓
Random Forest Model
↓
Prediction Response to iOS App

This is similar to how real ML-powered applications are built.

## Dataset

The dataset contains the following features:

| Feature        | Description                          |
| -------------- | ------------------------------------ |
| hours_studied  | Number of hours a student studied    |
| sleep_hours    | Average sleep hours                  |
| practice_tests | Number of practice tests completed   |
| pass_exam      | Target variable (0 = Fail, 1 = Pass) |

Example dataset row:

hours_studied: 6
sleep_hours: 7
practice_tests: 2
pass_exam: 1

---

## Machine Learning Model

Algorithm used:

Random Forest Classifier

Why Random Forest?

• Handles non-linear relationships well
• Reduces overfitting
• Uses ensemble learning (multiple decision trees)
• Works well with small datasets

Model training pipeline:

1. Load dataset
2. Split features and labels
3. Train-test split
4. Train Random Forest model
5. Evaluate model
6. Save model using Pickle

## Installation

Clone the repository:

```
git clone https://github.com/your-username/ios-ml-student-performance-predictor.git
```

Move into the project folder:

```
cd ios-ml-student-performance-predictor
```

Install dependencies:

```
pip install -r requirements.txt
```

---

## Train the Model

Run the training script:

```
python train_model.py
```

This will generate:

```
model.pkl
```

which is the trained machine learning model.

---

## Run the Backend API

Start the FastAPI server:

```
uvicorn main:app --reload
```

API will run at:

```
http://127.0.0.1:8000
```

Prediction endpoint:

```
POST /predict
```

Example request:

```
hours_studied=6
sleep_hours=7
practice_tests=2
```

Example response:

```
prediction: 1
```

---

## iOS Integration

The iOS application sends user input to the backend API and receives prediction results.

Example Swift request:

```
URLSession API call → FastAPI → Random Forest Model → Response
```

The result is displayed directly inside the mobile application.
